常见问题

怎么给程序输入数据（cin、input）？

有两种方法：① 直接运行，程序等待输入时，控制台下方的输入框会变成橙色，在里面输入后按回车发送；② 运行前打开“预设输入”，把所有输入一次填好，适合数据很多的题目。

编译错误看不懂怎么办？

出错的行会标成红色，控制台里会附上中文提示，告诉你大概是哪里错了。运行前 App 还会检查中文标点，发现中文分号“；”、中文括号“（）”等，会提示你一键改正。

支持哪些 C++ 标准？

C++11、C++14、C++17 和 C++20。可以在“设置”里切换，也可以点写代码页面右上角显示的标准（例如“C++17”）切换。也支持 #include <bits/stdc++.h> 万能头文件。

为什么不能用 try / catch？

内置的 C++ 编译器暂不支持异常，用到 try、throw 的代码会编译失败。可以改用返回值或 if 判断来处理错误。

C++ 能读写文件、用多线程吗？

暂不支持读写文件（fstream、freopen）和多线程。练习时请把 freopen 先注释掉，直接从键盘输入。

Python 能用 numpy、turtle 吗？

不能。目前只包含 Python 标准库（例如 math、random、collections），不能安装第三方库，也不支持 turtle 这类需要图形窗口的功能。

第一次运行为什么比较慢？程序停不下来怎么办？

第一次运行时要先加载编译器或解释器，C++ 的编译器比较大，可能要等十几秒到几十秒，之后在 App 打开期间就很快了。程序一直不结束（比如写成了死循环）时，点“停止”即可。

作业保存在哪里？怎么备份、换手机？

作业保存在你的设备上，在“文件”App 的“我的 iPhone”（iPad 上为“我的 iPad”）→“编程练习”→“作业”里也能找到。

在“作业”页面或“设置”里选“导出全部作业（备份）”，会得到一个 zip 压缩包，每份作业是一个代码文件，在电脑上也能直接打开。换了手机后，用“导入代码文件或备份”选这个压缩包，就能恢复作业的名称和时间。

注意：删除 App 会同时删除所有作业，删除前请先备份。

怎么打开微信、QQ 里收到的代码文件？

在微信或 QQ 里点开文件，点右上角的“…”，选“用其他应用打开”，再选“编程练习”，文件就会导入为一份作业。支持 .cpp、.py、.txt 等格式，Windows 记事本、Dev-C++ 保存的 GBK 编码文件也能正确显示中文。

怎么把代码交给老师？

在写代码的页面打开“导出”，可以导出成代码文件、图片或 PDF，还可以附上运行结果，然后发到微信、QQ 或存到“文件”。
