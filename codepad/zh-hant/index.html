編程練習

在 iPhone 和 iPad 上離線執行 C++ 和 Python 程式碼

編程練習是一款寫程式、執行程式的練習工具。C++ 和 Python 程式碼直接在你的裝置上編譯執行，不需要連網，也不需要電腦；出錯時有中文提示，適合學生課後練習和完成作業。

常見問題

怎麼給程式輸入資料（cin、input）？

有兩種方法：① 直接執行，程式等待輸入時，主控台下方的輸入框會變成橘色，在裡面輸入後按 Return 送出；② 執行前打開「預先輸入」，把所有輸入一次填好，適合資料很多的題目。

編譯錯誤看不懂怎麼辦？

出錯的那一行會標成紅色，主控台裡會附上中文提示，告訴你大概是哪裡錯了。執行前 App 還會檢查全形標點，發現全形分號「；」、全形括號「（）」等，會提示你一鍵改正。

支援哪些 C++ 標準？

C++11、C++14、C++17 和 C++20。可以在「設定」裡切換，也可以點寫程式頁面右上角顯示的標準（例如「C++17」）切換。也支援 #include <bits/stdc++.h> 萬用標頭檔。

為什麼不能用 try / catch？

內建的 C++ 編譯器暫不支援例外，用到 try、throw 的程式碼會編譯失敗。可以改用回傳值或 if 判斷來處理錯誤。

C++ 能讀寫檔案、用多執行緒嗎？

暫不支援讀寫檔案（fstream、freopen）和多執行緒。練習時請先把 freopen 註解掉，直接從鍵盤輸入。

Python 能用 numpy、turtle 嗎？

不能。目前只包含 Python 標準函式庫（例如 math、random、collections），不能安裝第三方套件，也不支援 turtle 這類需要圖形視窗的功能。

第一次執行為什麼比較慢？程式停不下來怎麼辦？

第一次執行時要先載入編譯器或直譯器，C++ 的編譯器比較大，可能要等十幾秒到幾十秒，之後在 App 開啟期間就很快了。程式一直不結束（例如寫成了無窮迴圈）時，點「停止」即可。

作業儲存在哪裡？怎麼備份、換手機？

作業儲存在你的裝置上，在「檔案」App 的「我的 iPhone」（iPad 上為「我的 iPad」）→「編程練習」→「作业」資料夾裡也能找到。

在「作業」頁面或「設定」裡選「匯出全部作業（備份）」，會得到一個 zip 壓縮檔，每份作業是一個程式碼檔案，在電腦上也能直接開啟。換了手機後，用「匯入程式碼檔案或備份」選這個壓縮檔，就能還原作業的名稱和時間。

注意：刪除 App 會同時刪除所有作業，刪除前請先備份。

怎麼開啟其他 App 裡收到的程式碼檔案？

在 LINE、微信、郵件等 App 裡打開檔案，用「分享」或「以其他 App 開啟」選擇「編程練習」，檔案就會匯入為一份作業。支援 .cpp、.py、.txt 等格式，Windows 記事本、Dev-C++ 儲存的 Big5 或 GBK 編碼檔案也能正確顯示中文。

怎麼把程式碼交給老師？

在寫程式的頁面打開「匯出」，可以匯出成程式碼檔案、圖片或 PDF，還可以附上執行結果，然後用通訊軟體傳送或儲存到「檔案」。
