Code Practice

Run C++ and Python code offline on iPhone and iPad

Code Practice is an app for writing and running code. C++ and Python programs compile and run right on your device, with no internet connection or computer needed. Plain-language hints explain errors, which makes it great for students practicing after class and doing homework. The interface is available in English, Simplified Chinese and Traditional Chinese.

FAQ

How do I give my program input (cin, input())?

There are two ways. (1) Just run it: when the program waits for input, the box at the bottom of the console turns orange; type there and press Return. (2) Before running, turn on “Preset Input” and enter all the input at once, which is handy when there is a lot of data.

I don’t understand a compile error. What can I do?

The line with the error is highlighted in red, and the console adds a plain-language hint about what is probably wrong. Before running, the app also checks for Chinese (full-width) punctuation such as “；” or “（）” and offers to fix it in one tap.

Which C++ standards are supported?

C++11, C++14, C++17 and C++20. Change it in Settings, or tap the standard shown at the top right of the code screen (for example “C++17”). #include <bits/stdc++.h> is supported too.

Why can’t I use try / catch?

The built-in C++ compiler doesn’t support exceptions yet, so code that uses try or throw won’t compile. Handle errors with return values or if checks instead.

Can C++ programs read or write files, or use threads?

Not yet. File I/O (fstream, freopen) and multithreading aren’t supported. When practicing, comment out freopen and type the input directly.

Can I use numpy or turtle in Python?

No. Only the Python standard library (such as math, random and collections) is included. Third-party packages can’t be installed, and turtle and other features that need a graphics window aren’t supported.

Why is the first run slow? What if my program never stops?

The first run has to load the compiler or interpreter. The C++ compiler is large, so this can take 10 to 30 seconds or more; after that it stays fast while the app is open. If a program never ends (for example an infinite loop), tap Stop.

Where is my homework saved? How do I back it up or move it to a new device?

Homework is saved on your device. You can also find it in the Files app under On My iPhone (On My iPad on iPad) → Code Practice → 作业 (the homework folder).

Choose “Export All Homework (Backup)” on the Homework screen or in Settings to get a zip archive with one code file per homework, which you can also open on a computer. On a new device, use “Import Code Files or Backup” and pick the archive to restore titles and dates.

Note: deleting the app also deletes all homework, so back up first.

How do I open code files I received in another app?

Open the file in Mail, WeChat or another app, tap Share (or “Open in”), and choose Code Practice. The file is imported as homework. .cpp, .py, .txt and other formats are supported, and files saved in UTF-8, GBK or Big5 display correctly.

How do I hand in my code?

On the code screen, open Export to export the code as a source file, an image or a PDF, optionally with the output, then send it or save it to Files.
